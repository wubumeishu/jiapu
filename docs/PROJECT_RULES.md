# 中国姓氏家谱·网络祭祖平台
# PROJECT RULES

## 1. 项目定位

本项目是“中国姓氏家谱·网络祭祖平台”。

核心功能包括：

- 姓氏查询
- 姓氏文化
- 家谱管理
- 家谱树
- 家族成员
- 家族关系
- 祖先纪念馆
- 网络祭祖
- 家族故事
- 家族相册
- 家族社区
- 家族活动
- 平台后台管理

## 3. 当前开发原则

当前最高优先级：

视觉还原 > 页面结构 > 交互 > 数据 > API > 架构扩展

第一阶段必须优先完成：

1. 页面视觉还原
2. 页面布局
3. UI 组件
4. 响应式
5. Mock 数据
6. 基础交互
7. 浏览器截图验证

在视觉没有达到目标以前：

不得优先进行复杂微服务架构建设。

---

## 4. 严格禁止

禁止：

- 擅自改变整体视觉风格
- 使用紫色作为主色
- 使用科技蓝作为主色
- 默认使用蓝白 SaaS 风格
- 擅自加入大面积渐变
- 擅自增加大型阴影
- 擅自增加营销模块
- 擅自修改页面结构
- 使用默认组件库样式作为最终设计
- 用静态图片代替可交互家谱树
- 用图片模拟真实页面功能
- 未经确认擅自进行视觉重设计

## 8. 架构原则

当前先使用模块化单体架构。

不要一开始引入：

- Kubernetes
- Kafka
- Nacos
- Sentinel
- Elasticsearch Cluster
- 微服务集群

未来根据真实用户规模和性能需求逐步升级。

## 10. 验收原则

任何页面完成以后必须进行：

- 浏览器实际运行
- 截图
- 与设计图对照
- Visual QA
- 响应式测试

页面只有达到视觉目标后，才进入下一阶段。
