---

## 1. QA 流程说明

每个页面完成后，执行以下检查流程：

```
1. 浏览器实际运行页面
2. 截图（同一分辨率、同一缩放级别）
3. 与设计图并排对比
4. 逐项勾选检查清单
5. 记录差异项
6. 修复后重新截图验证
```
