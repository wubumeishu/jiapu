## 零、核心原则

> **设计图是最终视觉目标，而不是普通参考图。**

- 所有实现必须以设计图为最高准则
- 不得以"理解偏差"或"自行优化"为由偏离设计图
- 有疑问时以设计图为准，而非经验判断
- 本规范是对设计图的精确翻译，不是再设计

## 一、修正汇总

### 1.1 颜色修正

| 修正项 | 旧值（错误） | 新值（正确） | 影响范围 |
|--------|-------------|-------------|----------|
| 女性家谱节点背景 | `#FCE4PC`（无效色） | `#FCE4EC`（淡粉） | 家谱树节点、QA清单 |

### 1.2 渐变规则重新定义

| 类别 | 规则 |
|------|------|
| ❌ 禁止 | 大面积、高对比度、装饰性渐变 |
| ✅ 允许 | 后台侧边栏极弱深咖色渐变（#352F2A → #2C2622），此为当前视觉设计的一部分 |

渐变限制说明：
- 允许范围仅限于后台侧边栏背景
- 渐变对比度必须极低（不超过 10% 明度差）
- 不得在其他任何区域使用渐变

### 1.3 家谱树技术方向确认

**第一版技术方案：SVG + 自定义布局引擎**

- 不使用 d3-tree、vue-flow 等第三方 Tree UI 作为核心实现
- 使用原生 SVG 绘制家谱树
- 自定义布局算法控制节点位置
- 保证交互性和可访问性

### 1.4 Mock 数据统一

**首页第一版示例数据统一使用"张氏"**

- 姓氏推荐列表首推：张

## 四、QA 标准更新

### 4.1 验收标准（不再要求 Pixel Perfect）

| 维度 | 标准 |
|------|------|
| 结构一致 | 页面层级、区块划分与设计图一致 |
| 几何一致 | 尺寸、间距、比例与设计图一致（允许 ±5% 误差） |
| 视觉一致 | 颜色、字体、圆角、阴影与设计图一致 |
| 交互一致 | 按钮点击、悬停、输入反馈与设计图一致 |
| 截图差异检查 | 截图与设计图叠加，差异区域不超过 5% 像素 |

### 4.2 允许误差范围

| 元素 | 允许误差 |
|------|----------|
| 颜色值 | ±2% 饱和度/明度 |
| 尺寸 | ±5% |
| 间距 | ±4px |
| 字体大小 | ±1px |
| 圆角 | ±2px |
| 阴影强度 | ±10% |

## 六、下一步实现计划
